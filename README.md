# Boo지런한 하루 웹·아이폰 홈 화면 버전 v10

폴더 구조를 그대로 유지한 채 `index.html`을 Safari 또는 Chrome으로 열면 됩니다.

## 조작

- 화면 터치, 스페이스 또는 위 방향키: 점프
- 아래로 밀기, 길게 누르기 또는 아래 방향키: 땅에서만 엎드리기. 점프 중에는 낙하 속도에 영향을 주지 않음
- 우주: 위·아래 방향키로 무중력 유영. 장애물과 충돌 없음
- 시작 화면의 `오산부터 살펴보기 · 무적`: 오산부터 끝까지 충돌 없이 배경 확인

## v10 반영 내용

- 달리기 프레임의 몸 크기, 머리 높이, 중심축과 발 접지선을 다시 정규화했습니다.
- 12칸을 맞추기 위해 같은 그림을 반복하던 방식을 없애고, 고유한 8개 자세를 완전히 동일한 시간 간격으로 재생합니다.
- 순천향대의 교수 캐릭터는 느리게 걷는 엑스트라에서 큰 4프레임 대련 애니메이션으로 교체했습니다.
- 대련 장소에는 배경에 박힌 대형 거북선과 추진 화염이 함께 등장합니다. 교수와 거북선은 같은 월드 좌표를 사용하므로 동시에, 달리기 속도와 동일한 속도로 지나갑니다.
- 시작 화면에 `교수 대련·대형 거북선 살펴보기 · 무적` 항목을 추가했습니다.
- iPhone 홈 화면 설치를 위한 웹앱 매니페스트, 180·192·512px 아이콘, 세로 모드, 안전 영역, 전체 화면 모드와 오프라인 캐시를 추가했습니다.

## iPhone에서 설치하기

1. 이 폴더의 내용 전체를 HTTPS 웹 주소에 올립니다. `index.html`만 단독으로 올리면 이미지가 나오지 않습니다.
2. iPhone의 Safari에서 그 주소를 엽니다.
3. Safari의 공유 버튼을 누른 다음 `홈 화면에 추가`를 선택합니다.
4. 표시된다면 `웹 앱으로 열기`를 켜고 `추가`를 누릅니다.
5. 홈 화면의 `Boo지런` 아이콘으로 실행합니다. 첫 실행을 마친 뒤에는 게임 파일이 기기에 저장되어 오프라인에서도 열립니다.

로컬 파일을 AirDrop으로 옮겨 직접 여는 방식은 서비스 워커와 오프라인 설치가 동작하지 않을 수 있으므로 HTTPS 배포 주소를 사용하는 것이 가장 안정적입니다.

## v9 반영 내용

- 실제 달리기의 접지 → 하강 → 추진 → 체공 → 반대발 접지 순서를 기준으로 부의 달리기를 12프레임으로 다시 제작했습니다.
- 프레임마다 발의 접지선과 체공 높이를 보존하고, 코드로 덧붙였던 상하 흔들림을 제거해 발 미끄러짐과 뚝뚝 끊기는 움직임을 줄였습니다.
- 배경 속 언덕과 별도로 캐릭터가 실제로 밟는 주행면 고도를 추가했습니다. 부, 말티즈, 장애물, 음식, 그림자, 먼지가 모두 같은 경사 좌표를 사용합니다.
- 오산은 오래된 보도의 잔굴곡, 동탄은 평탄한 신도시 길, 순천향대는 후문부터 높아지는 오르막과 캠퍼스 굴곡, 어린이대공원은 완만한 산책로로 구성했습니다.

## 이전 반영 내용

- 달리기를 12프레임으로 다시 정리해 양팔과 양다리가 서로 반대로 교차하도록 만들고, 발바닥 기준선을 통일해 시작 시 떠 보이던 틈을 없앴습니다.
- 위·아래 동시 입력과 하강 중 아래 입력이 점프 물리를 바꾸지 않도록 완전히 분리했습니다.
- 오산 구간은 줄이고 순천향대 구간은 두 배 이상 늘렸습니다. 캠퍼스·빌라 랜드마크 간격도 넓혔습니다.
- 순천향대에 오르막 캠퍼스 풍경, 별도 빌라 4종, 학생·고양이, 천원의 아침밥 판넬과 사진을 참고한 거대한 교수 캐릭터를 넣었습니다.
- 피닉스는 제거하고 크기와 높이가 다른 거북선을 자주 등장시켰습니다.
- 우주 배경은 어둡고 별이 드문 색감으로 바꾸고, 타일을 교대로 반전해 양 끝 경계가 끊기지 않게 했습니다.
- 우주 원경의 이동을 지상보다 느리게 하고 속도선을 제거해 배경 반복이 덜 보이고 더 고요하게 느껴집니다.
- 우주에서 부와 말티즈는 서로 다른 6프레임 유영 동작을 사용합니다.

`assets` 폴더는 `index.html`과 항상 함께 두어야 합니다.
